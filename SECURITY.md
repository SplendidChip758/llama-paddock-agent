# Security Policy

The agents are part of llama-paddock and follow [its security policy](https://github.com/SplendidChip758/llama-paddock/security/policy): security fixes go into the next release, and older releases are not patched, so the fix is to update the agent.

## Reporting a Vulnerability

**Please don't open a public issue for security problems.**

Report privately through GitHub: go to this repository's [Security tab](https://github.com/SplendidChip758/llama-paddock-agent/security) and click **Report a vulnerability**. Reports about the agents filed in [llama-paddock](https://github.com/SplendidChip758/llama-paddock/security) are welcome too.
